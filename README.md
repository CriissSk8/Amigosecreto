# 🎁 Amigo Secreto - Aplicación Web

Una aplicación web moderna y completa para organizar intercambios de regalos de amigo secreto de manera divertida y fácil.

## 🌟 Características

### ✨ Funcionalidades Principales
- **Registro de Participantes**: Cada persona puede registrarse con su información personal
- **Múltiples Regalos**: Los participantes pueden agregar hasta 5 opciones de regalos con sistema de prioridades
- **Sistema de Prioridades**: Cada regalo puede tener una prioridad (🥇 Primera, 🥈 Segunda, 🥉 Tercera opción, etc.)
- **Fotos de Regalos**: Posibilidad de adjuntar imágenes para cada regalo deseado
- **Valores en COP**: Sistema para indicar valores en pesos colombianos
- **Sorteo Inteligente**: Algoritmo que asigna automáticamente los amigos secretos
- **Visualización Completa**: Vista detallada de todos los participantes y sus múltiples opciones de regalos

### 🎨 Características de Diseño
- **Responsive**: Se adapta perfectamente a móviles, tablets y escritorio
- **Moderno**: Interfaz atractiva con gradientes y animaciones
- **Intuitivo**: Navegación por pestañas fácil de usar
- **Sistema de Colores por Prioridad**: Cada prioridad tiene su propio color distintivo
- **Accesible**: Diseño pensado para todos los usuarios

### 🛠️ Funcionalidades Avanzadas
- **Ordenamiento**: Ordena por nombre, valor total o fecha de registro
- **Almacenamiento Local**: Los datos se guardan automáticamente en el navegador
- **Exportación Detallada**: Descarga los resultados con todas las opciones de regalos
- **Envío por Email**: Comparte los resultados completos por correo
- **Panel de Administración**: Funciones adicionales para gestionar el evento

## 🚀 Cómo Usar la Aplicación

### 1. 📝 Registrar Participantes

1. Abre la aplicación en tu navegador web
2. Ve a la pestaña **"Registrarse"**
3. Completa el formulario con:
   - **Nombre completo** (obligatorio)
   - **Primer regalo** (obligatorio):
     - Selecciona la prioridad (Primera, Segunda, Tercera opción)
     - Describe detalladamente el regalo
     - Indica el valor estimado en COP (opcional)
     - Agrega una foto de referencia (opcional)

4. **Agregar más regalos** (opcional):
   - Haz clic en "Agregar otro regalo"
   - Puedes agregar hasta 5 opciones diferentes
   - Cada una con su propia prioridad, descripción, valor y foto

5. Haz clic en **"Registrar Participante"**
6. ¡Listo! Aparecerás en la lista con todos tus regalos

### 2. 👥 Ver Participantes

1. Ve a la pestaña **"Ver Participantes"**
2. Aquí puedes:
   - **Ver todos los participantes** registrados con sus regalos prioritarios
   - **Ordenar** por nombre, valor total o fecha de registro
   - **Ver detalles completos** haciendo clic en cualquier tarjeta
   - **Eliminar participantes** si es necesario (desde el detalle)

### 3. 🎲 Realizar el Sorteo

1. Ve a la pestaña **"Hacer Sorteo"**
2. Necesitas **mínimo 2 participantes** para hacer el sorteo
3. Haz clic en **"Realizar Sorteo"**
4. El algoritmo asignará automáticamente los amigos secretos
5. Verás los resultados con las asignaciones completas
6. Puedes:
   - **Descargar los resultados** con toda la información de regalos
   - **Enviar por email** la lista completa con prioridades
   - **Hacer un nuevo sorteo** si no te gusta el resultado

## 🎯 Consejos de Uso

### Para Organizadores:
- **Comparte el enlace**: Envía la URL de la aplicación a todos los participantes
- **Establece reglas claras**: Define el rango de precios en COP y fechas importantes
- **Sugiere múltiples opciones**: Recomienda que cada persona agregue 2-3 regalos con diferentes precios
- **Explica las prioridades**: Asegúrate que entiendan el sistema de prioridades

### Para Participantes:
- **Agrega varias opciones**: Incluye 2-5 regalos diferentes con distintos precios
- **Usa el sistema de prioridades**: Pon tu regalo favorito como primera opción
- **Sé específico**: Describe claramente cada regalo que te gustaría recibir
- **Incluye rangos de precios**: Agrega opciones económicas y otras más costosas
- **Agrega fotos**: Las imágenes ayudan mucho a quien te va a dar el regalo

### Ejemplo de buen registro:
- 🥇 **Primera opción**: Audífonos inalámbricos Sony ($200,000 COP)
- 🥈 **Segunda opción**: Libro "Cien años de soledad" ($50,000 COP)  
- 🥉 **Tercera opción**: Taza personalizada con mi nombre ($25,000 COP)

## 💰 Valores en Pesos Colombianos (COP)

- La aplicación está configurada para manejar valores en **pesos colombianos**
- Los campos de valor aceptan números enteros (sin decimales)
- Se sugiere usar incrementos de $1,000 COP para facilidad
- Los totales se muestran con formato de separadores de miles


Funciones disponibles:

- **💾 Exportar**: Descargar lista completa con todos los regalos

## ❓ Preguntas Frecuentes

### ¿Puedo agregar más de un regalo?
¡Sí! Puedes agregar hasta 5 regalos diferentes, cada uno con su propia prioridad.

### ¿Cómo funcionan las prioridades?
🥇 Primera = Lo que más quieres | 🥈 Segunda = Alternativa buena | 🥉 Tercera = También está bien

### ¿Puedo cambiar las prioridades después de registrarme?
No directamente, pero puedes eliminar tu registro y volver a registrarte.

### ¿Se pierden los datos si cierro el navegador?
No, los datos se guardan automáticamente y persisten entre sesiones.

### ¿Puedo cambiar el resultado del sorteo?
Sí, puedes hacer un nuevo sorteo las veces que quieras hasta que estés satisfecho.

### ¿El sorteo considera las prioridades?
No, el sorteo es aleatorio. Las prioridades son para que quien te dé el regalo sepa qué prefieres.
